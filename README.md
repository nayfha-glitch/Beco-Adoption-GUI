Beco Adoption program
Hi! This is a fun, small Java project I created for my university assignment to learn about Graphic User Interfaces (GUI).
What does it do?
The app simply asks you a question: "Will you adopt Beco and his daughter?".
The fun part? You can't say no. The program uses loops to playfully force you to click "Yes" eventually.
Built With:
1- Java
2- Java Swing & AWT (for the interface, buttons, and fonts)
What I learned:
I made this project to practice:
1- Creating windows using JFrame.
2- Making buttons interactive.
3- Using loops inside a GUI application.
